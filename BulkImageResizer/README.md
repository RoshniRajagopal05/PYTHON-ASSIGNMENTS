# Bulk Image Resizer

A Python application that resizes multiple images, generates thumbnails, and saves a processing report.

## Technologies Used
- Python
- Pillow

## Features
- Resize multiple images.
- Maintain aspect ratio.
- Save images in JPEG or PNG format.
- Adjust JPEG quality.
- Generate thumbnails.
- Handle corrupted images.
- Generate a CSV processing report.
- Prevent overwriting existing files.

## How to Run

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:

   ```bash
   python main.py
   ```

3. Enter the required input when prompted.

## Parallel Execution

No additional files or folders need to run in a separate terminal. The application runs independently.
