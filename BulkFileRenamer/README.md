# Bulk File Renamer

A Python application that renames multiple files in a folder automatically using customizable naming patterns.

## Features

- Sequential file renaming
- Custom filename prefix
- Custom starting number
- File extension filtering
- Date-based naming
- Rename preview before execution
- Confirmation before renaming

## Technologies Used

- Python
- pathlib
- re
- datetime
- uuid

## How to Run

1. Clone or download the project.
2. Navigate to the project directory.
3. Run:

```bash
python bulk_file_renamer.py
```

## Requirements

- Python 3.x
